# AWS Cloud Security Governance Portfolio

## About this portfolio
A hands-on governance architecture portfolio demonstrating cloud security controls aligned to MAS TRM 2021, ISO 27001, and Singapore PDPA. Built on AWS Free Tier as part of a career transition from enterprise IAM (NatWest Group, 20 years) into Cloud Security Architecture and Cloud Governance Lead roles.

**Credentials:** CCSP | CAIGS (in progress) |
**Frameworks:** MAS TRM 2021 | ISO 27001 | NIST AI RMF | AWS Security Reference Architecture
